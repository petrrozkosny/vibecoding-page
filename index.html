Náplň kurzu — 2 dny

Od prvního promptu po publikovanou aplikaci

01Úvod do AI a Claude
  • Jak funguje generativní AI — klíčové pojmy
  • Co je vibe coding a čím se liší od klasického programování
  • Limity AI: halucinace, zastaralé informace, citlivá data
  • Výběr modelu podle úlohy — rychlý a levný vs. silný a pomalý
02Efektivní promptování
  • Anatomie dobrého promptu: kontext, cíl, omezení, formát výstupu
  • Nejdřív plán, potom kód
  • Iterativní zpřesňování po malých krocích
  • Když se AI zasekne: opravit, nebo začít novou konverzaci
03Personalizace Claude
  • Memory — trvalé preference
  • Projects — vlastní knowledge base
  • Skills a Styles — opakované workflow a formát odpovědí
  • Připojení Google Disku a Gmailu bez programování
04Kde s Claude pracovat
  • Přehled rozhraní: Chat, Cowork, Claude Code, Claude Design
  • Rozhodovací tabulka — co si na co vybrat
  • Artefakty — živé náhledy HTML a diagramů
  • Workflow: prototyp → commit → publikace
05GitHub a verzování
  • Základní pojmy: repo, commit, branch
  • Proč verzovat a jak se vrátit zpět
  • GitHub Pages — publikace webu zdarma
  • Co do repozitáře nepatří
06Praktický projekt: vlastní web
  • Tvorba portfolio stránky nebo vizitky
  • Iterace s Claude
  • Publikace na GitHub Pages
  • Napojení vlastní domény
07Interaktivní aplikace
  • Kalkulačka, formulář nebo kvíz
  • Trvalé ukládání dat — aplikace si pamatuje, co uživatel zadal
  • AI přímo uvnitř aplikace — vlastní nástroj, který sám přemýšlí
08Sub-agenti
  • Kontextové okno — proč AI v dlouhé konverzaci ztrácí přehled
  • Co je sub-agent: samostatný pomocník, který úkol vyřeší stranou
  • Vytvoření vlastního specialisty — např. kontrolor textů
  • Paralelní běh a přiřazení levnějšího modelu na jednoduché úkoly

Časté dotazy

01Opravdu nemusím umět programovat?
Ne. Celý kurz je postavený na tom, že popíšete, co chcete, a výsledek vzniká v dialogu s AI. Žádné programátorské znalosti nejsou potřeba.
02Co si z kurzu reálně odnesu?
Konkrétní výstupy: publikovaný web, interaktivní nástroj, automatizační skript, sadu promptů a certifikát. Ne jen poznámky.
03Potřebuji vlastní placený účet?
Ne. Na dobu výuky a týden po kurzu vám přiřadíme naši licenci. Pokud si účet založíte předem, ušetříme čas na začátku.
04Kde kurz probíhá?
Brno: Sochorova 38 (budova COMGUARD, 1. patro). Praha: Líbalova 1, Praha 11 – Chodov (budova Opatov Park). Ke kurzu se lze připojit i online.
05Jsem vývojář a chci jít hlouběji, máte navazující kurz?
Ano — Claude Code: autonomní agentní vývoj a MCP integrace (CLPRG1), kde se probírají CLI, CLAUDE.md, hooks, skills a MCP integrace.
